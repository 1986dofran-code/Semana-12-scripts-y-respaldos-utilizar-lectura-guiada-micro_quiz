# Glosario Técnico - Automatización y Reportes

| Término | Definición |
| :--- | :--- |
| **Script** | Archivo de texto que contiene un conjunto de instrucciones de programación que el computador ejecuta para realizar una tarea específica. |
| **Automatización** | Uso de tecnología y programas para realizar tareas repetitivas con la mínima intervención humana posible. |
| **CSV (Comma Separated Values)** | Formato de archivo de texto plano que organiza los datos en forma de tabla, separando las columnas por comas. |
| **Respaldo (Backup)** | Copia de seguridad de información importante que se realiza para prevenir la pérdida de datos en caso de fallos. |
| **Log (Bitácora)** | Archivo que registra cronológicamente los eventos, éxitos y errores ocurridos durante la ejecución de un programa. |
| **Validación de Datos** | Proceso de verificar que la información ingresada cumpla con las reglas y formatos necesarios para ser procesada correctamente. |
| **Módulo (Module)** | Archivo de Python que contiene código (funciones o variables) diseñado para ser reutilizado en diferentes partes de un proyecto. |
| **Ruta (Path)** | Dirección única que indica la ubicación de un archivo o carpeta dentro del sistema de archivos de la computadora. |
| **Reporte** | Documento organizado que presenta los resultados de un proceso o análisis de datos para facilitar la toma de decisiones. |
| **Argumento (CLI)** | Parámetro que se le envía a un programa desde la terminal para modificar su comportamiento (como elegir un archivo diferente). |
